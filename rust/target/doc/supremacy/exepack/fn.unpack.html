Expand description

Unpack an EXEPACK-compressed MZ executable.

Reproduces the stub’s memory model in a flat buffer: dest is dest_len paragraphs seeded with the packed load image (the program’s uncompressed head plus the compressed tail), then command blocks expand the tail backwards from the top. The returned fixup list and real cs:ip/ss:sp come from the block header — the values the stub passes to the far jump at 0x23B76.

§Errors

BadMz (no MZ/ZM or truncated header), MissingPack (no RB header at the entry CS), Corrupt (bad command byte or a read/write outside the image).
