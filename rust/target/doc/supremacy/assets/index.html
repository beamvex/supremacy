.BIN/.GPH asset-set loading.

Port of the loader pair in GAME.unpacked.exe: .GPH index read + in-place paragraph fixup (0x3208E-0x320E9) and the chunked .BIN heap load (0x320F2-0x3215A). Filename buffers at ds:0x1242/ 0x124D are ???.??? templates the video-mode select patches with MCG/EGA/CGA/TGA + .BIN/.GPH; here the stem is a parameter.

Structs§

AssetSet
A loaded asset set: the fixed-up .GPH index plus the whole .BIN payload, mirroring the post-loader memory state (ds:0x158 records + heap segment 0x3A22).

Functions§

heap_segment
Heap segment formula from the loaders (0x320C6-0x320D5): (0x9CC4 - 0x7D39) >> 4, round up one paragraph, + 0x3829 (the program’s dest_len). Evaluates to 0x3A22 — the paragraph right after the loaded image where the .BIN data lands.
load_bin
Port of the .BIN loader at 0x320F2-0x3215A: the asm loops int 21/3F with cx=0xFFF0, bumping ds by 0xFFF paragraphs per chunk until a short read. Flat host memory makes it a single read — the result is identical.
load_index
Port of the .GPH loader at 0x3208E-0x320E9: read the index into ds:0x158, then run the 0x320D8 fixup loop adding heap_seg to every record’s ofs_para.
load_set
Load one asset set — dir/STEM.GPH + dir/STEM.BIN — the way the game does for e.g. MCG/EGAIN/CGAWIN.
