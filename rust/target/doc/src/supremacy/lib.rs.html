1//! Rust rewrite of the reverse-engineered assembly routines from
2//! *Supremacy: Your Will Be Done* (Probe Software, 1991), `GAME.EXE`.
3//!
4//! Every routine is a port of a specific routine in the unpacked 16-bit
5//! image (`decompiled/GAME.unpacked.exe`); file offsets cited in each
6//! module refer to that file and to `decompiled/disasm/GAME.linear.asm`.
7//! See `decompiled/ANALYSIS.md` for the full reverse-engineering report.
8//!
9//! - [`exepack`]: Microsoft EXEPACK unpacker (stub at file `0x23A90`).
10//! - [`lzss`]: the Okumura LZSS decoder used by all four video modes
11//!   (file `0x2EBEF`, `0x2EC8C`, `0x2FC5D`, `0x2FCF9`).
12//! - [`gph`]: the 12-byte `.GPH` image index records.
13//! - [`args`]: the command-line parser (`GAME <C/T/E/M> <K> <P/T/A/R>`,
14//!   file `0x31FF8`–`0x3207D`).
15//! - [`assets`]: `.BIN`/`.GPH` asset-set loading and record decoding
16//!   (loaders at file `0x3208E`–`0x3215A` onwards).
17//! - [`palette`]: the master MCGA DAC table (file `0x15034`).
18
